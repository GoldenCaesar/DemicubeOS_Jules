# Missions Folder

Mission packs live in their own folders.

## Rules
- Each pack has a `pack.json` manifest.
- Each mission has its own folder with a `manifest.json` file.
- Mission logic scripts can be added later beside each manifest.

## Add a mission
1. Create a mission folder under an existing pack.
2. Add a `manifest.json` file.
3. Add the mission id to the pack's `pack.json` list.
